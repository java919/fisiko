# **App Name**: WellnessFlow

## Core Features:

- Gestión de Clientes y Servicios (Admin): El administrador puede registrar nuevos clientes, asignarles servicios (sesiones puntuales o bonos de Fisioterapia, Pilates, etc.) y marcar las sesiones como completadas, actualizando el conteo de sesiones restantes automáticamente. Se registrará la fecha y hora de finalización de cada sesión.
- Automatización y Personalización de Correos: Al completar una sesión, se enviará automáticamente un correo electrónico personalizable al cliente informando las sesiones restantes. El administrador puede editar hasta 5 plantillas de correo por bono con ofertas exclusivas, incluyendo el logo y la firma del negocio.
- Calendario y Gestión de Disponibilidad (Admin): El administrador podrá definir y gestionar los horarios disponibles para reservas de citas en un calendario intuitivo.
- Panel Personalizado del Cliente: Los clientes podrán acceder a su panel personalizado para visualizar sus servicios contratados, el número de sesiones restantes, el historial de sesiones completadas y agendar nuevas citas según la disponibilidad establecida por el administrador.
- Contenido Exclusivo por Servicio (Admin y Cliente): El administrador podrá subir y gestionar contenido (texto, fotos, videos) clasificado por tipo de servicio. Los clientes, desde su panel, podrán acceder a este contenido específico de los servicios que tienen contratados.
- Sistema de Chat Interno: Implementación de un chat directo para comunicación fluida entre el administrador y los clientes, con notificaciones de mensajes nuevos para ambas partes.

## Style Guidelines:

- Color principal (interacciones, elementos clave): Naranja-amarillo vibrante (#e89428).
- Color secundario (textos oscuros, fondos de sección): Gris oscuro (#4b4b4b).
- Color de acento (resaltados, estados activos): Amarillo brillante (#f1bf1f).
- Color de fondo (claro, suave): Un tono crema muy sutil derivado del color principal (#fcfbf8).
- Fuentes para titulares: 'Space Grotesk' (sans-serif) para un toque moderno y técnico.
- Fuentes para el cuerpo de texto: 'Inter' (sans-serif) para una legibilidad óptima en dashboards y contenidos.
- Iconografía limpia y de línea, reflejando el profesionalismo y la claridad de la aplicación.
- Diseño intuitivo y receptivo con navegación clara para administradores y un panel centrado en el usuario para clientes. Utilizará tarjetas para visualizar información clave y secciones de contenido.
- Animaciones sutiles para transiciones entre vistas, retroalimentación al interactuar con el calendario y notificaciones de chat.
